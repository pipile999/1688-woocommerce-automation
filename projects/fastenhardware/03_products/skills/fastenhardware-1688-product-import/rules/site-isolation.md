# fastenhardware production boundary
Only https://fastenhardware.com. Fixed Runner: sites/fastenhardware/runner.py. Domain equality is exact and checked before credentials and again before every authenticated request. Redirects and non-product endpoints are forbidden. No --site, --root, --run-dir or profile overrides.
All runtime paths resolve inside sites/fastenhardware; symlinks/junctions/hardlinks to data are forbidden. Credentials come only from this site's .env; inherited credentials must never be used as a fallback. Google credentials and SEO cache/map are site-local. Existing historical data is retained as history, not automatically loaded or resumed. Migrate only explicitly verified same-site data when a later task needs it.
Runtime .env is an empty credential template on initial split; configure secrets locally before future production. Never print or submit secrets. This refactor does not authorize any product operation.
For any rule referring to output/ or data/, resolve relative to sites/fastenhardware/. Model and tool binaries may be shared, but outputs and caches must not be. Per-offer upload-checkpoint.json remains in the site's output/auto-runner tree.
Runner changes product content, variations, product categories and associated media only. Never edit global Product Template, theme, pages or plugins. Keep existing related products, recommendations, inquiry CTA and trust/service modules.
